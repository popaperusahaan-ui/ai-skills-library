# Contributing to AI Skills Library

Thank you for your interest in AI Skills Library!

We welcome suggestions, feedback, bug reports, and improvements that help make this collection of AI skills more useful and reliable.

## Ways to Contribute

You can contribute by:

- Suggesting new AI skills.
- Reporting issues or errors.
- Improving existing skill documentation.
- Recommending better instructions and workflows.
- Reporting security vulnerabilities privately.

## Contribution Guidelines

Every skill contribution should be:

- Clear and well-structured.
- Practical and reusable.
- Focused on a specific task or capability.
- Properly documented.
- Compatible with its declared target tools.
- Free from malicious instructions and exposed secrets.

## Skill Structure

Each skill should follow this structure:

    skill-name/
    └── SKILL.md

## Submitting Suggestions

1. Check existing skills to avoid duplicates.
2. Open a GitHub Issue.
3. Explain the proposed improvement or new skill.
4. Provide examples when possible.

## Code Ownership

AI Skills Library is maintained by its repository owner.

Public access does not grant permission to modify the original repository directly. Contributions and proposed changes are subject to review and approval by the owner.

## Security

Do not publish API keys, passwords, access tokens, or private credentials.

For security vulnerabilities, use the repository's private vulnerability reporting feature.

## Quality Standards

All accepted contributions should prioritize:

- Accuracy
- Clarity
- Reusability
- Reliability
- Maintainability
- Compatibility

Thank you for helping improve AI Skills Library!
