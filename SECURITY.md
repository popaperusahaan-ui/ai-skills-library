# Security Policy

## AI Skills Library Security

Security is an important priority for AI Skills Library.

We are committed to maintaining a safe, reliable, and trustworthy collection of AI skills.

## Supported Versions

Security updates are provided for the latest maintained version of AI Skills Library.

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |
| Older versions | No |

## Reporting a Vulnerability

If you discover a potential security vulnerability:

1. Do not publish sensitive vulnerability details publicly.
2. Use GitHub Private Vulnerability Reporting.
3. Provide a clear description of the issue.
4. Include steps to reproduce the problem when safe and appropriate.
5. Wait for the repository maintainer to review the report.

## Security Guidelines

All skills must:

- Avoid exposing API keys, passwords, and access tokens.
- Avoid malicious instructions.
- Avoid unauthorized access to systems or data.
- Respect user privacy.
- Use safe and responsible instructions.
- Avoid destructive operations without appropriate authorization.

## Sensitive Information

Never commit the following information:

- API keys
- Passwords
- Authentication tokens
- Private credentials
- Personal confidential information

## Security Review

New and updated skills should be reviewed for:

- Malicious instructions
- Unsafe behavior
- Data exposure risks
- Unauthorized operations
- Documentation accuracy

## Responsible Disclosure

Security vulnerabilities should be reported privately so they can be reviewed and addressed before public disclosure.

Thank you for helping keep AI Skills Library secure.
