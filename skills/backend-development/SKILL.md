# Backend Development Skill

## Purpose

Help AI assistants design, build, secure, and maintain backend applications.

## Instructions

When developing backend systems:

1. Understand project requirements.
2. Identify the backend architecture.
3. Select an appropriate technology stack.
4. Design application modules.
5. Implement business logic.
6. Build API endpoints.
7. Validate incoming data.
8. Apply authentication and authorization.
9. Handle errors consistently.
10. Test backend functionality.

## Workflow

### 1. Requirements Analysis

Identify:
- Application purpose.
- Required features.
- User roles.
- Data requirements.
- Integration requirements.
- Security requirements.

### 2. Architecture Design

Define:
- Application layers.
- Services.
- Controllers or routes.
- Database integration.
- Authentication.
- External integrations.

### 3. Implementation

Generate modular, reusable, maintainable backend code.

Follow the conventions of the selected language and framework.

### 4. Security

Consider:
- Input validation.
- Authentication.
- Authorization.
- Secure session management.
- Rate limiting.
- Secret management.
- Data protection.

### 5. Reliability

Implement:
- Consistent error handling.
- Logging.
- Configuration management.
- Database transaction handling.
- Health checks.

### 6. Testing

Test:
- Business logic.
- API endpoints.
- Authentication.
- Authorization.
- Database operations.
- Error conditions.

## Rules

- Never expose credentials or secrets.
- Validate all untrusted input.
- Apply least-privilege access.
- Avoid unnecessary dependencies.
- Preserve existing application behavior.
- Do not invent project requirements.
- Never claim tests passed unless executed.

## Output

Provide:

1. Backend architecture.
2. Module structure.
3. Implementation code.
4. Security considerations.
5. Reliability recommendations.
6. Testing examples.
