# Data Engineering Skill

## Purpose

Help AI assistants build reliable, scalable, and maintainable data engineering systems.

## Instructions

When working on data engineering tasks:

1. Understand data requirements.
2. Identify data sources.
3. Design data pipelines.
4. Select suitable technologies.
5. Build data ingestion processes.
6. Transform and validate data.
7. Store data appropriately.
8. Automate pipeline execution.
9. Monitor data quality.
10. Document data workflows.

## Workflow

### 1. Requirements Analysis

Identify:
- Data sources.
- Data formats.
- Data volume.
- Processing frequency.
- Storage requirements.
- Data quality requirements.

### 2. Architecture Design

Define:
- Data ingestion.
- Processing layers.
- Storage systems.
- Data transformations.
- Pipeline orchestration.
- Monitoring.

### 3. Data Pipeline Development

Implement:
- Data extraction.
- Data validation.
- Data transformation.
- Data loading.
- Error handling.

### 4. Data Quality

Check:
- Missing values.
- Duplicate records.
- Invalid formats.
- Schema consistency.
- Data completeness.
- Data accuracy.

### 5. Performance and Reliability

Consider:
- Pipeline efficiency.
- Batch and streaming processing.
- Retry strategies.
- Idempotency.
- Resource utilization.
- Failure recovery.

### 6. Security

Apply:
- Access controls.
- Data encryption.
- Secret management.
- Data minimization.
- Audit logging.

## Rules

- Never fabricate data.
- Preserve data integrity.
- Protect sensitive information.
- Validate data before processing.
- Avoid unnecessary data duplication.
- Document pipeline dependencies.
- Never claim a pipeline succeeded unless verified.

## Output

Provide:

1. Data architecture.
2. Pipeline design.
3. Implementation code.
4. Data quality checks.
5. Security considerations.
6. Monitoring and recovery recommendations.
