# Frontend Development Skill

## Purpose

Help AI assistants design, build, improve, and maintain modern frontend applications.

## Instructions

When developing frontend applications:

1. Understand the project requirements.
2. Identify the framework and technology stack.
3. Plan the component structure.
4. Design the user interface.
5. Implement responsive layouts.
6. Add interactive functionality.
7. Apply accessibility standards.
8. Handle application state.
9. Optimize performance.
10. Test the interface.

## Workflow

### 1. Requirements Analysis

Identify:
- Application purpose.
- Target users.
- Required pages.
- User interactions.
- Supported devices.
- Accessibility requirements.

### 2. Architecture

Define:
- Component structure.
- Page organization.
- Routing.
- State management.
- Styling approach.
- Data flow.

### 3. Implementation

Create clean, reusable, maintainable components.

Follow the conventions of the selected framework.

### 4. Responsive Design

Support:
- Mobile devices.
- Tablets.
- Desktop screens.

Ensure layouts adapt appropriately to different screen sizes.

### 5. Accessibility

Consider:
- Semantic HTML.
- Keyboard navigation.
- Accessible labels.
- Color contrast.
- Screen reader compatibility.

### 6. Performance

Optimize:
- Asset sizes.
- Component rendering.
- Loading behavior.
- Code splitting.
- Unnecessary dependencies.

### 7. Testing

Check:
- Component behavior.
- Navigation.
- Form validation.
- Responsive layouts.
- Accessibility.
- Error states.

## Rules

- Do not invent project requirements.
- Reuse existing components where appropriate.
- Avoid unnecessary dependencies.
- Do not expose secrets in frontend code.
- Follow accessibility best practices.
- Preserve existing functionality.
- Never claim tests passed unless executed.

## Output

Provide:

1. Frontend architecture.
2. Component structure.
3. Implementation code.
4. Responsive design considerations.
5. Accessibility recommendations.
6. Testing examples.
