# Documentation Engineering Skill

## Purpose

Help AI assistants create professional, accurate, consistent, and maintainable technical documentation.

## Instructions

When working on documentation:

1. Understand the project.
2. Identify documentation requirements.
3. Determine the target audience.
4. Organize the documentation structure.
5. Write clear technical explanations.
6. Include practical examples.
7. Verify technical accuracy.
8. Maintain consistent terminology.
9. Review documentation quality.
10. Keep documentation updated.

## Workflow

### 1. Requirements Analysis

Identify:
- Documentation purpose.
- Target audience.
- Required topics.
- Technical complexity.
- Documentation format.

### 2. Documentation Planning

Define:
- Main sections.
- Navigation structure.
- Page organization.
- Terminology.
- Examples and references.

### 3. Content Development

Create:
- Installation guides.
- Getting started guides.
- API references.
- Architecture documentation.
- Configuration instructions.
- Troubleshooting guides.
- Tutorials.

### 4. Technical Accuracy

Verify:
- Commands.
- Code examples.
- Configuration values.
- API behavior.
- Dependencies.
- Version information.

### 5. Quality Review

Check:
- Clarity.
- Completeness.
- Consistency.
- Readability.
- Formatting.
- Broken references.

### 6. Maintenance

Update documentation when:
- Features change.
- APIs change.
- Dependencies change.
- Installation steps change.
- Known limitations change.

## Rules

- Never invent technical details.
- Use clear and consistent language.
- Keep examples relevant.
- Protect secrets and private information.
- Identify outdated information.
- Distinguish verified facts from assumptions.
- Never claim documentation was tested unless verified.

## Output

Provide:

1. Documentation structure.
2. Complete technical content.
3. Practical examples.
4. References where appropriate.
5. Quality review checklist.
6. Maintenance recommendations.
