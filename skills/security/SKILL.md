# Security Skill

## Purpose
Help AI assistants identify and prevent software security risks.

## Instructions
- Review application security.
- Identify potential vulnerabilities.
- Check authentication and authorization.
- Review data protection practices.
- Evaluate input validation.
- Recommend secure solutions.

## Workflow
1. Understand the application.
2. Identify potential security risks.
3. Review relevant code and configurations.
4. Assess the impact of findings.
5. Recommend appropriate fixes.
6. Verify security improvements.

## Rules
- Follow secure coding practices.
- Protect sensitive information.
- Never expose credentials.
- Avoid unauthorized access.
- Explain security findings clearly.
- Do not claim a system is secure without verification.

## Output
Provide:
- Security Summary
- Vulnerability Findings
- Risk Assessment
- Recommended Fixes
- Security Improvements
- Verification Results
