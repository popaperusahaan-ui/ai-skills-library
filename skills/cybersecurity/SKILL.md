# Cybersecurity Skill

## Purpose

Help AI assistants improve the security of software, applications, APIs, networks, and infrastructure through defensive security practices.

## Instructions

When performing cybersecurity tasks:

1. Understand the system and its security requirements.
2. Identify assets that need protection.
3. Establish the authorized scope of assessment.
4. Review architecture and security configurations.
5. Identify potential vulnerabilities.
6. Assess risks and potential impact.
7. Recommend defensive improvements.
8. Verify security controls safely.
9. Document findings.
10. Recommend remediation and prevention measures.

## Workflow

### 1. Security Assessment

Identify:
- Application components.
- Data assets.
- User permissions.
- External integrations.
- Trust boundaries.
- Potential attack surfaces.

### 2. Threat Modeling

Evaluate:
- Potential threats.
- Security weaknesses.
- Likely impact.
- Existing defenses.
- Risk priorities.

### 3. Vulnerability Assessment

Review:
- Source code.
- Dependencies.
- Authentication.
- Authorization.
- Input validation.
- Configuration.
- Data protection.

Only assess systems within the authorized scope.

### 4. Defensive Security

Recommend:
- Strong authentication.
- Least-privilege access.
- Secure configuration.
- Encryption.
- Input validation.
- Logging and monitoring.
- Dependency maintenance.

### 5. Security Testing

Use safe, authorized methods to verify:
- Access controls.
- Input validation.
- Authentication behavior.
- Security configurations.
- Error handling.
- Dependency vulnerabilities.

Avoid disrupting systems or accessing data without authorization.

### 6. Incident Response

Help with:
- Understanding security alerts.
- Assessing potential impact.
- Preserving relevant evidence.
- Containing affected systems.
- Recovering securely.
- Documenting lessons learned.

### 7. Reporting

Document:
- Findings.
- Risk severity.
- Affected components.
- Evidence.
- Recommended fixes.
- Verification status.

## Rules

- Only assess systems with explicit authorization.
- Prioritize defensive security.
- Never expose passwords, tokens, or private keys.
- Do not access private data without permission.
- Avoid destructive testing.
- Do not provide instructions for unauthorized attacks.
- Explain security risks clearly.
- Never claim a vulnerability was fixed or verified without evidence.

## Output

Provide:

1. Security assessment.
2. Threat analysis.
3. Vulnerability findings.
4. Risk prioritization.
5. Recommended remediation.
6. Verification plan.
7. Security report.
