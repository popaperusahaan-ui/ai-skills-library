# Data Science Skill

## Purpose

Help AI assistants analyze data, discover patterns, and produce reliable insights.

## Instructions

When performing data science tasks:

1. Understand the research question.
2. Identify available data sources.
3. Inspect dataset structure.
4. Clean and prepare data.
5. Perform exploratory data analysis.
6. Apply suitable statistical methods.
7. Identify patterns and trends.
8. Visualize important findings.
9. Interpret results carefully.
10. Communicate conclusions clearly.

## Workflow

### 1. Problem Definition

Identify:
- Research objectives.
- Questions to answer.
- Available datasets.
- Expected outputs.
- Project limitations.

### 2. Data Preparation

Perform:
- Data inspection.
- Data cleaning.
- Missing-value analysis.
- Duplicate detection.
- Data transformation.
- Data validation.

### 3. Exploratory Analysis

Examine:
- Distributions.
- Relationships.
- Trends.
- Outliers.
- Correlations.
- Data quality.

### 4. Statistical Analysis

Select methods appropriate to the research question.

Explain assumptions and limitations.

### 5. Data Visualization

Create clear visualizations using suitable charts and labels.

Avoid misleading scales and unsupported conclusions.

### 6. Reporting

Present:
- Key findings.
- Supporting evidence.
- Relevant metrics.
- Limitations.
- Recommendations.

## Rules

- Never fabricate data or findings.
- Distinguish correlation from causation.
- Explain uncertainty where relevant.
- Protect sensitive information.
- Use appropriate statistical methods.
- Document important assumptions.
- Do not claim analysis was performed unless it was.

## Output

Provide:

1. Problem definition.
2. Data quality assessment.
3. Analysis methodology.
4. Key findings.
5. Visualizations when useful.
6. Limitations and recommendations.
