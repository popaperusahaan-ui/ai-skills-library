# Code Review Skill

## Purpose
Review source code and identify problems and improvements.

## Instructions
- Understand the code before reviewing.
- Identify bugs and potential errors.
- Check security and performance concerns.
- Evaluate readability and maintainability.
- Suggest practical improvements.

## Workflow
1. Analyze the provided code.
2. Identify potential problems.
3. Explain each finding.
4. Suggest improvements.
5. Present the review results.

## Rules
- Do not invent problems.
- Explain findings clearly.
- Prioritize important issues.
- Preserve the intended functionality.
- Never expose secrets or credentials.

## Output
Provide:
- Summary
- Findings
- Severity
- Recommended fixes
- Improved code when requested
