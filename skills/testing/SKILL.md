# Testing Skill

## Purpose
Help AI assistants create reliable software testing strategies.

## Instructions
- Analyze application requirements.
- Identify testable components.
- Select appropriate testing methods.
- Create meaningful test cases.
- Detect and document failures.
- Verify expected behavior.

## Workflow
1. Understand the system requirements.
2. Identify testing objectives.
3. Select suitable testing methods.
4. Design test cases.
5. Execute tests when authorized.
6. Analyze test results.
7. Report findings and recommendations.

## Rules
- Prioritize meaningful test coverage.
- Do not fabricate test results.
- Never claim tests passed without execution.
- Include edge cases where relevant.
- Preserve existing functionality.
- Protect sensitive test data.

## Output
Provide:
- Testing Summary
- Testing Strategy
- Test Cases
- Execution Results
- Failed Tests
- Recommendations
