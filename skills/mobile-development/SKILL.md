# Mobile Development Skill

## Purpose

Help AI assistants develop high-quality mobile applications for Android and iOS.

## Instructions

When developing mobile applications:

1. Understand application requirements.
2. Identify target platforms.
3. Select an appropriate technology stack.
4. Design application architecture.
5. Build user interfaces.
6. Implement application functionality.
7. Integrate APIs and databases.
8. Apply security practices.
9. Optimize performance.
10. Test on supported devices.

## Workflow

### 1. Requirements Analysis

Identify:
- Application purpose.
- Target users.
- Android and iOS requirements.
- Required features.
- Device compatibility.
- Offline functionality.

### 2. Architecture Design

Define:
- Application structure.
- Navigation.
- UI components.
- State management.
- Data storage.
- API integration.

### 3. Implementation

Create modular, maintainable mobile application code.

Follow the conventions of the selected framework.

### 4. User Experience

Consider:
- Simple navigation.
- Responsive layouts.
- Accessibility.
- Loading states.
- Error messages.
- Platform conventions.

### 5. Security

Consider:
- Secure local storage.
- Authentication.
- Permission management.
- API communication.
- Protection of sensitive data.

### 6. Performance

Optimize:
- Application startup.
- Memory usage.
- Battery consumption.
- Network requests.
- Image and asset loading.

### 7. Testing

Test:
- Application functionality.
- Navigation.
- Device compatibility.
- API integration.
- Offline behavior.
- Error handling.

## Rules

- Do not invent project requirements.
- Follow Android and iOS platform guidelines.
- Request only necessary permissions.
- Never expose API keys or credentials.
- Avoid unnecessary dependencies.
- Preserve existing functionality.
- Never claim tests passed unless executed.

## Output

Provide:

1. Mobile architecture.
2. Project structure.
3. Implementation code.
4. UI and UX recommendations.
5. Security considerations.
6. Testing examples.
