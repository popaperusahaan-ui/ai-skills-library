# Performance Optimization Skill

## Purpose

Help AI assistants identify performance bottlenecks and improve software efficiency without compromising reliability or security.

## Instructions

When optimizing software:

1. Understand performance requirements.
2. Establish a baseline.
3. Identify bottlenecks.
4. Measure resource usage.
5. Analyze execution behavior.
6. Prioritize improvements.
7. Implement targeted optimizations.
8. Benchmark the results.
9. Check for regressions.
10. Document performance changes.

## Workflow

### 1. Performance Assessment

Identify:
- Application response times.
- Memory consumption.
- CPU utilization.
- Network latency.
- Database performance.
- Expected workload.

### 2. Bottleneck Analysis

Examine:
- Slow functions.
- Inefficient algorithms.
- Database queries.
- Network requests.
- Resource-intensive operations.
- Unnecessary rendering.

### 3. Optimization Strategy

Consider:
- Efficient algorithms.
- Caching.
- Database indexing.
- Asynchronous processing.
- Resource management.
- Asset optimization.
- Appropriate concurrency.

### 4. Implementation

Apply targeted improvements while preserving existing behavior.

Avoid unnecessary complexity and premature optimization.

### 5. Benchmarking

Measure:
- Response time.
- Throughput.
- Memory usage.
- CPU usage.
- Resource consumption.

Compare results against the original baseline.

### 6. Regression Testing

Verify:
- Existing functionality.
- Data correctness.
- Application stability.
- Security controls.
- Performance under expected workloads.

## Rules

- Measure before optimizing.
- Do not invent benchmark results.
- Preserve application correctness.
- Do not weaken security for speed.
- Avoid unnecessary dependencies.
- Explain trade-offs.
- Never claim performance improved without comparative evidence.

## Output

Provide:

1. Performance assessment.
2. Identified bottlenecks.
3. Optimization recommendations.
4. Implementation examples.
5. Benchmarking methodology.
6. Regression testing checklist.
7. Remaining limitations.
