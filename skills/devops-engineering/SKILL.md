# DevOps Engineering Skill

## Purpose

Help AI assistants design, implement, and maintain reliable DevOps workflows and infrastructure.

## Instructions

When working on DevOps tasks:

1. Understand deployment requirements.
2. Identify the application architecture.
3. Select suitable infrastructure.
4. Design CI/CD pipelines.
5. Automate build and deployment processes.
6. Configure environments.
7. Manage infrastructure.
8. Monitor application health.
9. Improve reliability and security.
10. Document operational procedures.

## Workflow

### 1. Requirements Analysis

Identify:
- Application requirements.
- Deployment targets.
- Infrastructure needs.
- Availability requirements.
- Budget constraints.
- Security requirements.

### 2. Infrastructure Design

Define:
- Servers and hosting.
- Networking.
- Storage.
- Containers.
- Environment configuration.
- Backup strategy.

### 3. CI/CD

Design workflows for:
- Source validation.
- Automated testing.
- Build processes.
- Deployment.
- Release management.

### 4. Infrastructure Automation

Use appropriate tools to manage:
- Infrastructure configuration.
- Container environments.
- Deployment settings.
- Reproducible environments.

### 5. Monitoring

Consider:
- Application health.
- Logs.
- Performance metrics.
- Error tracking.
- Resource usage.
- Alerts.

### 6. Security

Apply:
- Least-privilege permissions.
- Secret management.
- Dependency updates.
- Secure configurations.
- Access auditing.

### 7. Reliability

Plan:
- Backups.
- Recovery procedures.
- Deployment rollback.
- Failure handling.
- Capacity planning.

## Rules

- Never expose secrets or credentials.
- Do not make production changes without authorization.
- Prefer repeatable and documented processes.
- Avoid unnecessary infrastructure complexity.
- Validate configurations before deployment.
- Do not claim deployment succeeded unless verified.

## Output

Provide:

1. DevOps architecture.
2. Infrastructure plan.
3. CI/CD configuration.
4. Automation examples.
5. Security recommendations.
6. Monitoring and recovery plan.
