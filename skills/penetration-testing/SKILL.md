# Penetration Testing Skill

## Purpose

Help AI assistants plan and document authorized penetration testing to improve system security.

## Instructions

When conducting penetration testing:

1. Confirm explicit authorization.
2. Define the assessment scope.
3. Identify permitted testing methods.
4. Review the target architecture.
5. Assess security controls.
6. Identify potential vulnerabilities.
7. Evaluate security risks.
8. Document findings.
9. Recommend remediation.
10. Verify fixes safely.

## Workflow

### 1. Authorization and Scope

Establish:
- System ownership.
- Written authorization.
- Testing boundaries.
- Permitted activities.
- Testing schedule.
- Emergency contact.

### 2. Security Reconnaissance

Review authorized information about:
- Application architecture.
- Exposed services.
- Technology stack.
- Security configurations.
- Authentication boundaries.

### 3. Vulnerability Assessment

Examine:
- Access control weaknesses.
- Authentication configuration.
- Input validation.
- Security headers.
- Dependency vulnerabilities.
- Information disclosure.

### 4. Security Validation

Use non-destructive methods to validate identified weaknesses.

Avoid accessing private information or disrupting services.

### 5. Risk Assessment

Classify findings according to:
- Severity.
- Potential impact.
- Likelihood.
- Affected components.
- Remediation priority.

### 6. Remediation

Recommend:
- Configuration improvements.
- Security patches.
- Access control changes.
- Secure coding practices.
- Additional monitoring.

### 7. Reporting

Prepare a clear report containing findings, evidence, limitations, and recommended fixes.

## Rules

- Require explicit authorization.
- Never test systems outside the approved scope.
- Do not perform destructive testing.
- Do not steal credentials or private data.
- Do not establish unauthorized persistence.
- Do not evade security monitoring.
- Protect all assessment evidence.
- Never claim a test succeeded without verification.

## Output

Provide:

1. Authorization and scope summary.
2. Assessment methodology.
3. Security findings.
4. Risk classification.
5. Remediation recommendations.
6. Verification plan.
7. Final security report.
