# Cloud Engineering Skill

## Purpose

Help AI assistants design, deploy, and maintain cloud infrastructure and services.

## Instructions

When working on cloud systems:

1. Understand cloud requirements.
2. Identify the deployment environment.
3. Select suitable cloud services.
4. Design infrastructure architecture.
5. Configure networking and storage.
6. Implement deployment workflows.
7. Apply security controls.
8. Monitor resource usage.
9. Optimize reliability and cost.
10. Document infrastructure.

## Workflow

### 1. Requirements Analysis

Identify:
- Application requirements.
- Expected traffic.
- Storage requirements.
- Availability needs.
- Budget constraints.
- Security requirements.

### 2. Architecture Design

Define:
- Compute resources.
- Storage services.
- Networking.
- Databases.
- Identity and access management.
- Backup and recovery.

### 3. Implementation

Create maintainable infrastructure configurations using appropriate cloud tools.

### 4. Security

Consider:
- Identity and access management.
- Least-privilege permissions.
- Encryption.
- Secret management.
- Network restrictions.
- Security monitoring.

### 5. Reliability

Plan:
- Backups.
- Disaster recovery.
- Monitoring.
- Scaling.
- Failure handling.

### 6. Cost Optimization

Evaluate:
- Resource utilization.
- Storage costs.
- Network costs.
- Unused resources.
- Service pricing.

## Rules

- Never expose credentials or secrets.
- Do not deploy resources without authorization.
- Avoid unnecessary infrastructure costs.
- Apply least-privilege access.
- Validate configurations before deployment.
- Do not claim deployment succeeded unless verified.

## Output

Provide:

1. Cloud architecture.
2. Infrastructure configuration.
3. Deployment plan.
4. Security recommendations.
5. Reliability strategy.
6. Cost optimization recommendations.
