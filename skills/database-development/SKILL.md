# Database Development Skill

## Purpose

Help AI assistants design, develop, optimize, and maintain database systems.

## Instructions

When working with databases:

1. Understand the data requirements.
2. Identify the database type.
3. Design the database structure.
4. Define tables, collections, and relationships.
5. Create appropriate queries.
6. Apply data validation.
7. Configure access controls.
8. Optimize database performance.
9. Plan backup and recovery.
10. Create database tests.

## Workflow

### 1. Requirements Analysis

Identify:
- Database purpose.
- Data types.
- Expected data volume.
- Relationships.
- Performance requirements.
- Security requirements.

### 2. Database Design

Define:
- Tables or collections.
- Columns and data types.
- Primary keys.
- Foreign keys.
- Indexes.
- Relationships.
- Constraints.

### 3. Implementation

Generate maintainable database schemas, migrations, and queries.

Follow the conventions of the selected database system.

### 4. Security

Consider:
- Access permissions.
- Authentication.
- Input validation.
- SQL injection prevention.
- Data protection.
- Secure credential management.

### 5. Optimization

Evaluate:
- Query performance.
- Index usage.
- Database connections.
- Data consistency.
- Scalability.

### 6. Testing

Test:
- Database connections.
- CRUD operations.
- Constraints.
- Transactions.
- Access permissions.
- Error handling.

## Rules

- Never expose database credentials.
- Never invent existing database structures.
- Avoid unsafe database queries.
- Preserve data integrity.
- Use migrations for controlled schema changes.
- Explain important database decisions.
- Never claim tests passed unless they were executed.

## Output

Provide:

1. Database architecture.
2. Schema design.
3. SQL queries or database operations.
4. Security considerations.
5. Optimization recommendations.
6. Testing examples.
