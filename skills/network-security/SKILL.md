# Network Security Skill

## Purpose

Help AI assistants design, assess, and improve network security using defensive security practices.

## Instructions

When working on network security:

1. Understand network architecture.
2. Identify protected assets.
3. Define authorized assessment scope.
4. Review network configurations.
5. Identify security weaknesses.
6. Evaluate network risks.
7. Recommend defensive controls.
8. Review monitoring capabilities.
9. Document findings.
10. Verify security improvements.

## Workflow

### 1. Network Assessment

Identify:
- Network topology.
- Connected devices.
- Network boundaries.
- Critical services.
- Access requirements.
- Existing security controls.

### 2. Configuration Review

Examine:
- Firewall policies.
- Router configurations.
- Network segmentation.
- Wireless security.
- Remote access settings.
- Device management.

### 3. Threat Assessment

Evaluate:
- Unauthorized access risks.
- Misconfigured services.
- Weak access controls.
- Insecure communications.
- Unnecessary network exposure.

### 4. Defensive Improvements

Recommend:
- Network segmentation.
- Secure firewall rules.
- Strong authentication.
- Encryption.
- Secure wireless configurations.
- Regular updates.
- Least-privilege access.

### 5. Monitoring

Consider:
- Network logs.
- Security alerts.
- Unusual traffic patterns.
- Device activity.
- Configuration changes.

### 6. Verification

Confirm that approved security improvements work as intended without disrupting network operations.

## Rules

- Only assess networks with authorization.
- Never access networks without permission.
- Do not disrupt network services.
- Never expose network credentials.
- Avoid unnecessary changes to production configurations.
- Protect network logs and sensitive information.
- Never claim a security improvement was verified without evidence.

## Output

Provide:

1. Network architecture assessment.
2. Configuration review.
3. Risk analysis.
4. Defensive recommendations.
5. Monitoring strategy.
6. Verification checklist.
