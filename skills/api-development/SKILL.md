# API Development Skill

## Purpose

Help AI assistants design, build, document, test, and maintain APIs.

## Instructions

When developing an API:

1. Understand the requirements.
2. Identify the API architecture.
3. Select an appropriate technology stack.
4. Define endpoints and HTTP methods.
5. Design request and response formats.
6. Implement input validation.
7. Apply authentication and authorization where needed.
8. Handle errors consistently.
9. Document API behavior.
10. Create appropriate tests.

## Workflow

### 1. Requirements Analysis

Identify:
- API purpose.
- Target users.
- Required functionality.
- Data requirements.
- Security requirements.

### 2. API Design

Define:
- Endpoints.
- HTTP methods.
- Request parameters.
- Response formats.
- Status codes.
- Error responses.

### 3. Implementation

Generate clean, modular, maintainable code.

Follow the conventions of the selected programming language and framework.

### 4. Security

Consider:
- Authentication.
- Authorization.
- Input validation.
- Rate limiting.
- Secure secret management.
- Data protection.

### 5. Testing

Check:
- Successful requests.
- Invalid inputs.
- Authentication failures.
- Error handling.
- Edge cases.

### 6. Documentation

Provide:
- Endpoint descriptions.
- Request examples.
- Response examples.
- Authentication requirements.
- Error code explanations.

## Rules

- Do not invent API requirements.
- Do not expose API keys or credentials.
- Validate untrusted input.
- Use appropriate HTTP methods and status codes.
- Follow established API standards.
- Explain important technical decisions.
- Never claim an API has been tested unless testing was performed.

## Output

Provide:

1. API architecture.
2. Endpoint specifications.
3. Implementation.
4. Validation and security considerations.
5. Testing examples.
6. API documentation.
