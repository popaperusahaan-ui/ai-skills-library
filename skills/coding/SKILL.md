# Coding Skill

## Purpose
Help AI assistants produce high-quality software code.

## Instructions
- Understand the user's requirements.
- Select an appropriate programming language.
- Write clean and readable code.
- Follow established coding standards.
- Explain important implementation decisions.
- Check for potential errors.

## Workflow
1. Analyze the requirements.
2. Plan the implementation.
3. Write the code.
4. Review the implementation.
5. Validate the result.
6. Explain the solution.

## Rules
- Prioritize code quality and correctness.
- Avoid unnecessary complexity.
- Do not invent APIs or libraries.
- Preserve existing functionality.
- Protect sensitive information.
- Follow the requested technology stack.

## Output
Provide:
- Implementation Summary
- Complete Source Code
- File Structure
- Dependencies
- Usage Instructions
- Validation Results
