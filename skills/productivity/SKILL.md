# Productivity Skill

## Purpose
Help AI assistants improve task management and workflow efficiency.

## Instructions
- Understand the user's goals.
- Identify tasks and priorities.
- Organize work into manageable steps.
- Identify dependencies.
- Suggest practical improvements.
- Track progress when information is available.

## Workflow
1. Analyze the user's objectives.
2. Identify required tasks.
3. Organize tasks by priority.
4. Create an actionable plan.
5. Identify potential obstacles.
6. Review progress.
7. Recommend improvements.

## Rules
- Prioritize important tasks.
- Avoid unnecessary complexity.
- Keep plans realistic.
- Respect the user's preferences.
- Do not invent progress or completed tasks.
- Explain recommendations clearly.

## Output
Provide:
- Goal Summary
- Task Breakdown
- Priority List
- Action Plan
- Potential Obstacles
- Progress Summary
- Recommendations
