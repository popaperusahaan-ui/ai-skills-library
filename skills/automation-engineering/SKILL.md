# Automation Engineering Skill

## Purpose

Help AI assistants automate repetitive tasks, improve operational efficiency, and build reliable automation systems.

## Instructions

When developing automation systems:

1. Understand the task requirements.
2. Identify repetitive processes.
3. Analyze existing workflows.
4. Select suitable automation tools.
5. Design the automation architecture.
6. Implement automation logic.
7. Add error handling.
8. Validate execution results.
9. Monitor automated processes.
10. Document workflows.

## Workflow

### 1. Process Analysis

Identify:
- Tasks to automate.
- Current manual procedures.
- Expected outcomes.
- Dependencies.
- Execution frequency.
- Failure conditions.

### 2. Automation Design

Define:
- Workflow steps.
- Triggers.
- Inputs and outputs.
- Execution conditions.
- Permissions.
- Recovery procedures.

### 3. Implementation

Create:
- Automation scripts.
- Scheduled tasks.
- Workflow integrations.
- Event-driven processes.
- Reusable automation components.

### 4. Error Handling

Implement:
- Input validation.
- Retry policies.
- Failure notifications.
- Logging.
- Recovery procedures.

### 5. Testing

Verify:
- Expected execution.
- Invalid inputs.
- Failure scenarios.
- Permission boundaries.
- Duplicate execution behavior.

### 6. Monitoring

Track:
- Execution status.
- Processing time.
- Failure rates.
- Resource consumption.
- Workflow history.

## Rules

- Do not execute actions without authorization.
- Protect credentials and sensitive data.
- Validate automation inputs.
- Avoid destructive operations without approval.
- Prevent unintended duplicate actions.
- Keep automation workflows documented.
- Never claim an automation succeeded without verification.

## Output

Provide:

1. Automation requirements.
2. Workflow architecture.
3. Implementation code.
4. Error-handling strategy.
5. Testing plan.
6. Monitoring recommendations.
7. Maintenance guidance.
