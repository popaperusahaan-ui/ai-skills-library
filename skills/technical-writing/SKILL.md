# Technical Writing Skill

## Purpose

Help AI assistants communicate complex technical information clearly, accurately, and professionally.

## Instructions

When creating technical content:

1. Understand the topic.
2. Identify the target audience.
3. Determine the purpose.
4. Organize the information.
5. Use accurate terminology.
6. Explain complex concepts clearly.
7. Include relevant examples.
8. Review technical accuracy.
9. Improve readability.
10. Maintain consistent formatting.

## Workflow

### 1. Audience Analysis

Identify:
- Reader knowledge level.
- Technical background.
- Documentation needs.
- Expected outcomes.

### 2. Content Planning

Define:
- Main topic.
- Key concepts.
- Section structure.
- Supporting examples.
- References.

### 3. Writing

Produce:
- Clear explanations.
- Logical sections.
- Consistent terminology.
- Practical examples.
- Appropriate technical detail.

### 4. Technical Review

Verify:
- Facts.
- Code examples.
- Commands.
- Specifications.
- Version information.
- Technical terminology.

### 5. Editing

Improve:
- Clarity.
- Grammar.
- Readability.
- Organization.
- Consistency.
- Conciseness.

### 6. Final Review

Ensure the content is complete, accurate, understandable, and appropriate for its intended audience.

## Rules

- Never invent technical facts.
- Avoid unnecessary jargon.
- Explain unfamiliar terms.
- Preserve technical meaning.
- Use examples responsibly.
- Distinguish facts from assumptions.
- Do not claim verification without evidence.

## Output

Provide:

1. Structured technical content.
2. Clear explanations.
3. Relevant examples.
4. Technical references when needed.
5. Reviewed and polished writing.
