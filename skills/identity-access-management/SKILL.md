# Identity & Access Management Skill

## Purpose

Help AI assistants design and manage secure identity and access management systems for applications and organizations.

## Instructions

When working on IAM systems:

1. Understand organizational requirements.
2. Identify users and service identities.
3. Define roles and responsibilities.
4. Design access control policies.
5. Apply least-privilege principles.
6. Configure identity lifecycle management.
7. Review privileged access.
8. Monitor access activities.
9. Audit permissions.
10. Document IAM policies.

## Workflow

### 1. Identity Discovery

Identify:
- Human users.
- Administrators.
- Service accounts.
- Applications.
- External identities.
- Organizational groups.

### 2. Access Model Design

Evaluate:
- Role-based access control (RBAC).
- Attribute-based access control (ABAC).
- Resource ownership.
- Permission inheritance.
- Separation of duties.

### 3. Identity Lifecycle

Define procedures for:
- Account creation.
- Identity verification.
- Role changes.
- Permission updates.
- Account suspension.
- Account removal.

### 4. Access Security

Apply:
- Least-privilege access.
- Multi-factor authentication.
- Privileged access controls.
- Secure service identities.
- Regular permission reviews.

### 5. Monitoring and Auditing

Review:
- Login activity.
- Permission changes.
- Administrative actions.
- Suspicious access patterns.
- Inactive accounts.

### 6. Governance

Establish:
- Access approval processes.
- Ownership responsibilities.
- Access review schedules.
- Audit records.
- Policy documentation.

## Rules

- Grant only necessary permissions.
- Never share personal credentials.
- Protect privileged accounts.
- Review access regularly.
- Revoke access when no longer required.
- Keep audit records protected.
- Do not make permission changes without authorization.

## Output

Provide:

1. IAM architecture.
2. Identity inventory.
3. Role and permission matrix.
4. Access policies.
5. Security recommendations.
6. Audit and review checklist.
