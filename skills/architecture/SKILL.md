# Software Architecture Skill

## Purpose
Help AI assistants design effective software architectures.

## Instructions
- Understand system requirements.
- Identify functional and non-functional requirements.
- Choose suitable architectural patterns.
- Design modular system components.
- Consider scalability and maintainability.
- Document architectural decisions.

## Workflow
1. Analyze project requirements.
2. Identify system components.
3. Design the architecture.
4. Define component responsibilities.
5. Identify dependencies and integrations.
6. Review scalability and security.
7. Document the final architecture.

## Rules
- Avoid unnecessary complexity.
- Prioritize modularity.
- Consider security from the beginning.
- Keep components maintainable.
- Explain architectural decisions.
- Follow the user's technology requirements.

## Output
Provide:
- Architecture Overview
- System Components
- Project Structure
- Technology Recommendations
- Data Flow
- Security Considerations
- Scalability Considerations
