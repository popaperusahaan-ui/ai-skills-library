# Getting Started

Welcome to AI Skills Library!

This guide explains how to find and use skills from this repository.

## 1. Browse Skills

Open the `skills/` directory and choose a category.

Available categories include:

- Coding
- Debugging
- Code Review
- Architecture
- Security
- Testing
- Research
- Writing
- Productivity

## 2. Select a Skill

Open the skill folder you want to use.

Each skill contains a `SKILL.md` file with its instructions.

## 3. Read the Instructions

Review the skill's:

- Purpose
- Instructions
- Workflow
- Rules
- Output

## 4. Use a Skill

Copy the relevant skill instructions into a compatible AI assistant or coding tool.

Follow the tool's documentation for installing or importing custom skills.

## 5. Customize a Skill

You can adapt skill instructions to your project requirements.

Keep the original purpose and structure clear.

## 6. Create a New Skill

Use the template located at:

`templates/skill-template/SKILL.md`

Follow the standard skill structure.

## Important Notes

- Compatibility depends on the AI tool.
- Review instructions before using a skill.
- Never include API keys or passwords.
- Verify important AI-generated results.
