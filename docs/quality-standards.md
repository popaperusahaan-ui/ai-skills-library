# Quality Standards

This document defines the quality requirements for Skills published in AI Skills Library.

## 1. Clear Purpose

Every Skill must have:
- A specific purpose.
- A clearly defined scope.
- A useful description.
- Practical use cases.

## 2. Consistent Structure

Every Skill must include:

- YAML frontmatter.
- Purpose.
- Instructions.
- Workflow.
- Rules.
- Output.

## 3. Clear Instructions

Instructions should:
- Use simple and understandable language.
- Provide actionable guidance.
- Avoid unnecessary repetition.
- Explain expected behavior clearly.

## 4. Reusability

Skills should:
- Work across compatible AI tools.
- Avoid unnecessary platform dependencies.
- Support adaptation to different projects.
- Remain focused on their intended purpose.

## 5. Reliability

Skills should:
- Avoid unsupported claims.
- Identify uncertainty when necessary.
- Encourage verification of important information.
- Handle incomplete information appropriately.

## 6. Security and Privacy

Skills must not:
- Request unnecessary sensitive information.
- Expose passwords, API keys, or access tokens.
- Encourage unsafe handling of user data.
- Include malicious instructions.

## 7. Documentation

Every Skill must have:
- A meaningful name.
- A useful description.
- Organized instructions.
- A defined output format.

## 8. Maintenance

Skills should be reviewed periodically to:
- Correct outdated instructions.
- Improve clarity.
- Fix reported problems.
- Maintain compatibility.

## 9. Review Checklist

Before publishing a Skill:

- [ ] Purpose is clear.
- [ ] Metadata is complete.
- [ ] Required sections are present.
- [ ] Instructions are understandable.
- [ ] Security considerations are addressed.
- [ ] Validation passes.

## 10. Quality Goal

The goal is to maintain a library of Skills that are useful, reusable, understandable, and reliable.
