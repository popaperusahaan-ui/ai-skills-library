# Frequently Asked Questions (FAQ)

## 1. What is AI Skills Library?

AI Skills Library is a public collection of reusable Skills designed to improve AI assistant and coding tool workflows.

## 2. Is this an AI model?

No. AI Skills Library contains Skill instructions and documentation, not AI models.

## 3. Is this a Multi-Agent System?

No. It is a collection of individual Skills that can be used by compatible AI tools.

## 4. Who can use this repository?

Anyone can view, download, and use the Skills according to the repository license.

## 5. Do I need an API key?

Not necessarily. Skills are instruction files and do not require their own API keys. Your AI tool may have separate access or usage requirements.

## 6. How do I use a Skill?

1. Browse the `skills/` directory.
2. Select a Skill.
3. Open its `SKILL.md` file.
4. Follow the instructions for your AI tool.

## 7. Can I modify a Skill?

Yes. You can adapt Skills for your own needs, subject to the MIT License.

## 8. Which AI tools are supported?

Skills use portable Markdown instructions. Compatibility depends on whether your AI tool can read and follow those instructions.

## 9. Can I contribute new Skills?

Yes. Read `CONTRIBUTING.md` before submitting a contribution.

## 10. Are all Skills guaranteed to work perfectly?

No. Results depend on the AI tool, its capabilities, and how the Skill is used.

## 11. Does this repository reduce API costs?

Skills may help improve workflow efficiency, but they do not guarantee reduced API usage, token consumption, or costs.

## 12. Where can I report a problem?

Use the Bug Report template in the repository's GitHub Issues.

## 13. Where can I suggest a new Skill?

Use the Skill Request template in GitHub Issues.

## 14. What license does the repository use?

The repository uses the MIT License. Read the `LICENSE` file for the full terms.

## 15. How can I contact the project owner?

Use the repository's GitHub Discussions or Issues.
