# Skill Categories

AI Skills Library organizes reusable Skills into functional categories to make discovery and usage easier.

## 1. Software Development

Skills for writing, improving, and maintaining software.

Available Skills:
- `coding`
- `debugging`
- `code-review`

## 2. Software Architecture

Skills for planning and designing software systems.

Available Skills:
- `architecture`

## 3. Security

Skills for improving software security and identifying potential vulnerabilities.

Available Skills:
- `security`

## 4. Quality Assurance

Skills for testing software and improving reliability.

Available Skills:
- `testing`

## 5. Research and Analysis

Skills for gathering information and evaluating sources.

Available Skills:
- `research`

## 6. Writing and Documentation

Skills for producing clear and structured content.

Available Skills:
- `writing`

## 7. Productivity

Skills for organizing tasks and improving workflows.

Available Skills:
- `productivity`

## Adding New Categories

New categories may be introduced when the library grows.

Each new Skill should have:
- A clearly defined purpose.
- A suitable category.
- A dedicated directory.
- A `SKILL.md` file.

## Goal

Make Skills easier to discover, understand, organize, and reuse.
