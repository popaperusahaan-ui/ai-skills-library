# Compatibility

AI Skills Library is designed to provide reusable skills across different AI assistants and coding tools.

## 1. Compatibility Goals

- Cross-platform usability.
- Portable skill instructions.
- Consistent skill structure.
- Minimal tool-specific dependencies.
- Easy adaptation.

## 2. Supported Tool Categories

The library aims to support compatible:

- AI coding assistants.
- AI-powered IDEs.
- AI agent development tools.
- General-purpose AI assistants.
- Developer automation tools.

## 3. Using Skills Across Tools

1. Browse the `skills/` directory.
2. Select a suitable skill.
3. Read its `SKILL.md`.
4. Check your AI tool's custom instruction or skill support.
5. Adapt or import the instructions according to that tool's documentation.

## 4. Compatibility Requirements

Tools should support:

- Reading Markdown instructions.
- Following structured instructions.
- Processing task workflows.
- Using relevant context provided by users.

## 5. Tool-Specific Adaptation

Some AI tools require specific folder structures, metadata, or installation methods.

Adapt the skill when necessary without changing its original purpose.

## 6. Limitations

- Not every tool supports native skill installation.
- Some tools may require manual instruction copying.
- Advanced features may vary between tools.
- Compatibility must be tested individually.

## 7. Future Improvements

AI Skills Library aims to improve:

- Cross-tool compatibility.
- Standardized skill formats.
- Documentation.
- Validation.
- Reusability.
